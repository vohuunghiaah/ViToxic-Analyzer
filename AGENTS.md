# Workspace rules

After any code writing, editing, or debugging, open and update `AI_TRACKER.md` before the final response:
- Record changes under `Lịch sử thay đổi`.
- Record discovered unresolved defects under `Lỗi còn tồn đọng`.
- Mark fixed defects `[x]`.
- Add relevant optimization proposals under `Đề xuất cải thiện`.

Use NumPy primitives for numerical kernels and resampling math; rasterio is for raster I/O. Keep tests and documentation consistent with actual behavior. Do not mark learner self-assessment checkboxes automatically.
